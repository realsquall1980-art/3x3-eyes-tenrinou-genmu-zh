# 验收口径与证据（v6.9）

本仓库只发布补丁，不讲故事。下面每一句都能在本机交付记录里复核。

## 1. 改动边界

- 三碟的改动**只落在 DIR000 文本/字库区**：24,746 字节，`UNOWNED = 0`（越界写 = 0）。
- 补丁体积因此只有 100–170 KB 量级，而不是整盘镜像。

## 2. 补丁可逆性

- `UPS 往返 True × 3`：每碟都是「原盘 → 打补丁 → 反向打回原盘」，回打结果与原盘逐字节一致。
- 也就是说补丁是**可逆**的：留着原盘 Track 1，随时能退回日文版。

## 3. 成盘

- `CHD verify successful × 3`、`extractcd MATCH × 3`：从打好补丁的 cue 转 CHD，再从 CHD 反解回 BIN，与原 BIN 逐字节一致。
- 装机版曾在掌机上同名覆盖安装后**远端回读 SHA-256 三碟一致**（`SHA_MATCH × 3`）。

## 4. 屏幕验收（不是看日志，是看画面）

- 用模拟器对本作做**全流程冷启动录制**：59.94 fps、320×240、71,000 帧，从标题一路走到剧情对白，逐屏抽帧读图。
- 逐屏核对项：标题画面四行中文与署名 / 主菜单 / 游戏内暂停菜单六行 / 人物介绍屏正文 / 所在地说明屏 / 存读档界面 / 剧情对白与说话人名牌 / 过场动画中日双语字幕。
- 过场动画字幕：18 段有语音动画共 695 句逐句对位；另 5 段盘上音轨实测为静音，按「无台词」处理，不烧字幕。

## 5. 你自己怎么验

```bash
# 1) 补丁校验
shasum -a 256 -c SHA256SUMS.txt

# 2) 打补丁后与本文档记录比对（尺寸应与原盘 Track 1 完全一致：UPS 不改长度）
ls -l "Track 1.bin"

# 3) 进游戏看五处：标题四行 / 暂停菜单六行 / 人物介绍正文 / 所在地说明正文 / 任意一段剧情对白
```

若第 3 步任何一处仍是日文或空白，先把版本号对一遍（v6.9），再检查是否打错碟。
